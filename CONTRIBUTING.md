# Contributing to NetDiag Toolkit

Thanks for helping improve NetDiag Toolkit.

## Before opening an issue

Please include:
- Windows version
- PowerShell version
- NetDiag version/commit
- Command used
- Relevant output
- Whether a proxy or firewall was enabled

Remove public IPs, MAC addresses, usernames and other private information before posting logs.

## Pull requests

1. Create a focused branch.
2. Explain the problem and the change.
3. Keep changes small and readable.
4. Avoid collecting or transmitting network data without explicit user action.
5. Update documentation when behavior changes.
6. Keep diagnostics read-only unless a future feature explicitly documents a change and asks for consent.
